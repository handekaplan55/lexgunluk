LEXGÜNLÜK — İLK ÇALIŞAN SÜRÜM

1. WINDOWS BİLGİSAYAR
Zip dosyasını çıkartın. WINDOWS_AC.bat dosyasına çift tıklayın.
Alternatif: index.html dosyasını Chrome/Edge ile açın.
İnternet olmasa bile içerikler ve yerel notlar tarayıcıda kullanılabilir (ilk yükleme sonrasında PWA önbelleği).

2. TELEFONDA (IPHONE)
İndirilen ZIP'i telefona göndermek tek başına ortak bir web sitesi oluşturmaz.
Uygulamayı HTTPS sunucusuna (ör. GitHub Pages) yayımlayın:
  a) GitHub hesabınızda yeni repository açın: lexgunluk
  b) Bu klasördeki dosyaları repository köküne yükleyin.
  c) Settings > Pages > Build and deployment > Deploy from a branch > main /root > Save.
  d) GitHub Pages bağlantısını iPhone Safari'de açın.
  e) Paylaş menüsü > Ana Ekrana Ekle > Web uygulaması olarak aç > Ekle.
Kaynak: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

3. ÖNEMLİ ÖZELLİK VE SINIRLAR
- Her takvim günü, gömülü doğrulanabilir kaynak havuzundan 1 okuma önerir.
- Kaydetme, okundu işareti, not alma, içerik ekleme, arama, kategori filtresi, JSON yedekleme çalışır.
- Kaynak havuzu şimdilik sınırlı; aynı içerikler ileriki tarihlerde dönebilir.
- Otomatik yeni kaynak toplama ve günlük gerçek bildirimler HENÜZ YOK.
- Ortak hesap/veritabanı YOK; bilgisayar ve iPhone kayıtları senkronize OLMAZ.
- İçerikler DergiPark ve AYM bağlantıları içerir; doğrulanmamış Yargıtay karar numarası uydurulmadı.
- Girilen kişisel kayıtlar yalnızca tarayıcı localStorage alanındadır. Gizli dosya veya müvekkil bilgisi kaydetmeyin.
- Her hukuki değerlendirmede orijinal metin, güncel mevzuat ve somut olay ayrıca kontrol edilmelidir.
