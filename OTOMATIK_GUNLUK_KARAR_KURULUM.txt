LEXGÜNLÜK TAMAMEN ÜCRETSİZ SÜRÜM — KURULUM

Ücretli OpenAI API kullanılmaz. Hiçbir API anahtarı gerekmez.

1. GitHub üzerinde herkese açık (public) LexGunluk isimli bir depo oluşturun.
2. ZIP içindeki dosyaları, .github klasörü dahil olacak şekilde depo köküne yükleyin.
3. Settings > Pages > Build and deployment > Deploy from a branch: main / (root), Save.
4. Actions sekmesinden "Ucretsiz gunluk hukuk makalesi secimi" görevini etkinleştirin.
5. Actions > Run workflow ile ilk çalıştırmayı deneyin. Günlük görev yaklaşık 08:15 Türkiye saatine planlıdır; GitHub'da gecikme olabilir.
6. https://KULLANICIADI.github.io/LexGunluk/ adresinde yayınlanır (adres depo ismine göre değişir).
7. iPhone: Safari > Paylaş > Ana Ekrana Ekle. Windows: Chrome/Edge > uygulama olarak yükle.
